# Finite-height barn aperture and a physically supported source witness

The conditional cafe-panel/gap hypothesis survives its finite-height constraint. Both cafe top endpoints 143/178 have clear finite rays from one constructed standing interior viewpoint in the recovered fixed scene. This supplies a source-geometry witness; it does not identify the native camera, admit image anchors, or complete V12/V14. No production or test code changed.

The exact [generator](analyze.py) retains the prior room footprint through wall-bottom vertices 178/193/224/186, source-XY skew, node matrices and rational binary64 arithmetic. The wall-bottom corners also differ slightly in Z and do not themselves establish the actual floor triangulation. The previous topology warning remains applicable.

For gap half-plane L, camera C and exterior target P, set D=L(C)−L(P)>0. At the aperture plane the ray's numerator is Nxy=−L(P)Cxy+L(C)Pxy and Nz=−L(P)Cz+L(C)Pz. For gap edge e=B−A, its finite-height inequality follows from comparing Nz/D against zA+(zB−zA)dot(Nxy/D−A,e)/dot(e,e). Multiplication by positive D and dot(e,e) gives an affine camera-XY half-plane when Cz is fixed. Each endpoint contributes both bottom and top inequalities in addition to the previous finite-XY cone inequalities. Clipping and classification use zero epsilon.

For an initial necessary condition, camera Z lies in the wall-bottom Z interval plus 85 source units. The bottom inequality uses the maximum possible eye height and the top inequality the minimum, allowing the favorable height separately. Consequently this is a conservative **conditional necessary region**, not an exact set of supported cameras throughout the footprint. It adds no area: all finite-height inequalities retain the previous five-vertex region of 18,815.463798670156 source-unit², approximately 10.51544% of the footprint.
