# Source miss/puff default up correction — 2026-10-01

The current miss and RPG puff renderer incorrectly shared blood's explicit source-Z up hint. Both recovered editions instead omit the optional up argument for those two actors: `miss.ls` line21 calls `pointAt(oldpos)` and `puff.ls` line16 calls `pointAt(goody.pmod)`. Blood line31 explicitly supplies `vector(0,0,1)`. These are preserved source-script operations, not original runtime observations.

The primary [Director MX2004 scripting reference, printed page458](https://eclass.hmu.gr/modules/document/file.php/TP194/drmx2004_scripting_ref.pdf#page=458) states that the omitted up argument uses world Y, with world X replacing it when the object's forward direction is parallel to world Y. The cached primary PDF and source-script hashes are retained in the [focused validation manifest](../../../artifacts/fidelity-review/2026-10-01/current/source-effect-default-up-focused-validation.json). No Director, Flash, Lingo, ActionScript or original movie was executed.

Source Y maps to copy negative Z; source X maps to copy positive X. `OriginalCombatEffectPresentation.face` now gives miss/puff those world up hints and selects the documented X fallback for an exactly parallel nonzero direction. It does not use Three's small direction perturbation to choose that pole. Blood retains its explicit source Z/copy Y hint. Existing miss self-X180 rotation and puff constructor-only facing followed by its random self-Z roll are preserved.

For a miss on a copy-positive-X-facing wall, the preceding implementation produced world image-right positive Z and image-up negative Y after the source X180 turn. The corrected omitted-up rule produces image-right positive Y and image-up positive Z. This is a 90-degree texture-roll difference, independently checked using cardinal world axes. Puff orientation likewise changes before its existing random roll; its random roll distribution can make a single rendered comparison less informative than exact seeded basis checks.

The focused presentation suite passes **20 tests**, including cardinal miss and puff bases, both source-Y pole directions, preserved puff10-degree seeded roll, blood's explicit-Z basis, existing callback lifetime/texture updates and rotated-parent miss placement. `npx tsc --noEmit` passes.
