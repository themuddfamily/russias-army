# Barrel angular state, geometry and rendering integration

Barrack's preserved barrel now carries the shared angular-body adapter. This implements the coherent state/geometry/render/snapshot path identified in [the integration map](ORIGINAL_ANGULAR_INTEGRATION_MAP.md). It does not establish native Havok COM/inertia construction, rotational CCD/manifolds, callback notification cadence, barrel hurt behavior or historical assisted-jump height. No original runtime or GPU was executed for this bounded work.

`OriginalBarrelWorld.reset` creates identity orientation and zero angular velocity for the original complete world-oriented hull, preserving mass 1, restitution .2, friction 1 and the ten-source-unit lift. Body position remains the model pivot; the shared solver owns COM integration. Restored metadata is rederived from the preserved template and mass rather than accepted from packets.

Snapshots now emit paired orientation quaternion and world angular velocity in degrees/second. Snapshot restoration validates the entire replacement list before mutation: known unique IDs, finite position/velocity, paired finite angular fields and quaternion norm within 1e-6 of unity. Accepted quaternion coordinates are normalized. Legacy snapshots omitting both angular fields restore identity/zero. Returned and restored mutable vectors/quaternions are detached; absent bodies remain absent until an explicit restore/reset.

`getModelMatrix(id)` supplies one coherent full source-basis matrix for both the queried mesh and Three renderer. It rotates the imported matrix's three linear columns by the body's relative world quaternion through the source/world axis conversion, retains imported scale, and sets translation from the current rendered pivot. Identity orientation preserves the original linear matrix exactly. Query geometry cache keys include orientation as well as position. Contained-player checks use the full current angular hull, retaining the original bottom pivot and all source points. The renderer no longer independently guesses barrel translation or spin.
