# Coherent reconstructed angular physics — 2026-10-01

The copy now carries evolving angular state through shared projectile/barrel physics, collision geometry, rendered model pivots and authority snapshots. This addresses the fixed-orientation gap identified in [the integration map](ORIGINAL_ANGULAR_INTEGRATION_MAP.md). It is an explicit reconstruction; it does not establish Havok-native mass properties, integration, rotational CCD or historical explosive-jump behavior.

## Source requirements and adapter choices

Recovered movable bodies are unpinned. Grenades and RPGs zero angular velocity at birth; subsequent grenade contact callbacks multiply linear velocity by .85, while RPG actor callbacks restore linear launch speed. Neither callback zeroes spin. Source schedule, gravity, masses, restitution, friction, fuse and launch metadata are retained. See [the primary-document audit](ORIGINAL_HAVOK_ANGULAR_DEFAULTS_AUDIT.md).

`shared/originalAngularBody.ts` integrates a uniform closed convex volume to reconstruct COM and a full symmetric inertia tensor. The source did not specify this distribution and reviewed primary documents do not prove it is the native default. Public angular velocity uses degrees/second. The body quaternion rotates the retained complete world-oriented launch/import hull. Body position is the model pivot; linear velocity is COM velocity. Rotation advances around COM and reconstructs the pivot. Torque-free midpoint integration preserves world angular momentum; zero elapsed time is an exact no-op. Immutable hull/mass metadata is shared; mutable pose/velocity state is cloned.

Finite clipped face patches retain actual surface pairs. Near-parallel floor handling clips an actual hull facet and reconstructs the actual triangle plane rather than choosing a distant support corner. Coplanar triangle patches at the selected impact epoch are aggregated to avoid triangulation-seam torque. Contacts exchange equal/opposite point impulses using world inertia. The manifold solver uses accumulated normal and vector Coulomb friction impulses, up to 128 iterations with a velocity-scaled convergence tolerance. Native manifold selection and notification cadence remain unproved.

Rotation is sampled within each source substep using fixed-orientation swept full hulls, bounded by five degrees and half the positive contact skin in surface travel. This is not a proof of native rotational CCD. The existing 48 collision-iteration limit remains; exhausted iterations can leave residual time unintegrated. Repeated numerical grenade-contact callbacks remain visible; no arbitrary contact throttle or spin damping was added.

## Runtime integration

Shared world pair filtering uses the relative predicted model-pivot travel; patch positions use the same swept pivot path as narrowphase. Surface closing checks use angular point velocity and, for movable partners, relative partner velocity. Fixed-scene and door queries forward point-velocity callbacks. Both standalone and joint projectile paths retain spin after actor callbacks.

Three projectile meshes compose immutable launch orientation with current body rotation. The preserved barrel imported matrix, complete collision hull and geometric queries use the same evolving quaternion and pivot. Snapshot fields are paired optional `orientation`/`angularVelocity`, validated for finite components and quaternion unit norm; legacy omission restores identity/zero. Prediction and packet adoption clone dynamic state. No protocol version bump was required for these additive fields.
