# Five-to-six weapon history: new contemporary player evidence

The early five-slot instruction now has a concrete historical explanation. Dated player comments on the same [January 2008 article](https://www.kotaro269.com/articles/9700.html) describe adding the Dragunov later that year. This supports a version change rather than treating the original guide as an unexplained omission. It does not establish the exact publisher release date or build number.

The [preserved HTML](weapon-slot-2008/article.html) and [provenance](weapon-slot-2008/provenance.json) record exact bytes, SHA256, comment anchors, displayed dates, identities and bounded excerpts. Direct HTTPS retrieval and the web index independently exposed the relevant comments. The legacy EUC-JP page contains malformed characters elsewhere; none occur in the four extracted comment blocks. No original executable or script runtime was executed.

This is firsthand historical player testimony, not a publisher changelog or an authenticated original 2008 executable. The current page preserves displayed timestamps; this retrieval does not independently authenticate their 2008 publication. Nevertheless, the five-family list, two explicit addition reports and later numbered-six description form a coherent chronology. Do not equate the July observation date with a proven release date.

For the selected target, existing [recovered-script observations](../2026-09-30/DIRECTOR_SCRIPT_OBSERVATIONS.md) establish six weapons in both preserved editions, while the [sharp Woodland reference observations](../2026-09-30/REFERENCE_OBSERVATIONS.md) independently show six HUD rows. Retain all six. D02 can now be assessed against a documented historical expansion instead of the previously missing explanation; broader native runtime fidelity remains a separate requirement.
