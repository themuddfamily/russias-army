# Recovered RPG convex integration

The earlier [shape reconstruction](ORIGINAL_RPG_COLLISION_SHAPE.md) is now integrated into Barrack and Woodland gameplay. This replaces the transverse sphere that omitted most of the recovered rocket resource. Checklist G06/V28 remain open: these changes reconstruct source geometry and translation, not native Havok execution.

The shared RPG body retains all 72 unique support points from all 195 decoded vertices, the authored offset pivot, 76 outward hull faces and 114 triangulation edge directions. A radius about the pivot serves broadphase rejection only. Continuous world queries test actual finite scene triangles; dynamic queries dispatch convex/sphere or convex/convex relative motion. Sphere contact uses closed-hull face, edge and vertex distances, including containment. Convex pairs retain every face axis and edge cross axis. Joint separation uses returned penetration depth and inverse masses, rather than sphere-center distance.

Client solo and joint physics, standalone contacts, predicted network flight, authority reconciliation and puff replay consume the same shape. The authoritative room consumes the same world and dynamic queries. Door wrappers delegate the query to their movement geometry: closed panels block the full nose, and source opening immediately removes that collision while visible combat rays continue following animation.

Protocol 9 transports exact pre-recoil source rotation in degrees. Ordinary source Y remains zero. Provided angles must be finite and agree with ballistic direction; negotiated source RPG shots and snapshot/spawn state require them. The shape and mesh preserve angles beyond the principal pitch branch and retain yaw at vertical flight. Standalone non-negotiated legacy fixtures explicitly derive a principal-branch orientation when no angles are supplied; that compatibility path does not establish recovered native orientation.

The rendered mesh uses the same complete basis as physics. Seven actual Game tests cover both maps, pitch113/yaw−2377, pre-recoil capture, prediction/adoption, retained puff epochs and vertical late joins. Every decoded rendered vertex agrees with its physical coordinate within `3.03e-8` copy units, reflecting Float32 vertex storage. Eight actual MatchRoom tests cover launch/event/snapshot retention, detached copies and rejection before ammunition/counter/history mutation. Additional shared tests exercise moving-player momentum, nose and rear, sphere rounded features, initial overlap and containment, relative movement, and closed/open/reset doors.

Repeated SAT work uses bounded projection caches only for deeply immutable input geometry. All source axes, ordering and numerical thresholds are retained. Pair caches hold at most eight partners per weakly held shape; world caches hold at most 64 triangle partners. Mutable generic inputs stay uncached. The local warm profile reported 100 hitting RPG pairs in1647→71.73ms, 300 Barrack world queries in678→31.51ms and 300 Woodland queries in287→13.04ms, with matching hit counts. These are local workload measurements, not historical runtime timing.

Native Euler/clone-parent semantics, rotational collision response, angular velocity, contact margins/manifolds, material combination and native scheduling remain unproved. This integration retains the copy's explicit translation-only physics adapter, source mass100/restitution1/friction0, launch offset/speed, ten substeps, callback200 maximum fuse and actor velocity reset. It does not settle the earlier grenade-assisted jump failures or original camera/raster registration. The full checklist remains active at27/40 accepted.
