The result contract distinguishes genuine refreshed hit, known-absent null and unsupported undefined. Unknown custom fixtures retain their existing compatibility behavior.

It does not choose the first all-touching result or a new global closest feature.

Visible transformed open panels stay ray-only under existing source policy.

Dynamic pairs retain their existing actual-pose refiner; registered fixed features now use the shared selected-feature refiner. Genuine current geometry retains the original selected positive fraction/time. Unchanged quaternions retain the translated sweep, preserving the zero-T roundoff guard and shared-reference cache behavior.

`/root/russias-army/shared/originalExplosives.ts` performs the corresponding registered fixed-feature check in its standalone angular substep after advance and before response. A genuine result refreshes normal/manifold data but preserves the selected scheduling fraction. A null result consumes the selected elapsed time and continues; it does not apply `.85`, hit flags, notification or separation. The actor counter still decrements only in its normal actor stage.

No original forces, material constants, `.85` source handler, actor fuse counters, configured T, distance tolerances, five-degree/half-T sampling, 48-event cap, response caps, source input rules or strict assisted-jump `>2` gates were changed.
