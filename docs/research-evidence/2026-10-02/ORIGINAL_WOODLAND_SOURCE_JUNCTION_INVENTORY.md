# Woodland finite source junctions and UV boundaries

The new [passive inventory](interior-source-junctions/source-junction-inventory.json), generated by [the source-only script](../../../scripts/research/inventory-original-shed-junctions.py), retains all 196 `woodenshed` triangles, 415 exact source vertices and their first decoded UV channel through 286 finite geometric edge groups. Both separated source components are retained: A and B each have 143 groups. Exact per-triangle endpoints, source/world coordinates, vertex indices, triangle IDs, existing source-plane IDs and raw endpoint UVs remain in each edge binding. No image matching, fitting, renderer or original runtime runs.

Duplicated vertices are grouped only where endpoints differ by less than 0.002 source units; this does not change any exact binding coordinates. Full finite triangle edges are inventoried, including unpaired edges. Partial collinear overlap and T-junctions are not reconstructed, so failure to find an incidence is not proof of a geometric hole. The existing source-plane inventory omits face 62, whose exact cross-product norm is zero; its edge bindings remain explicitly unassigned to a plane. An [initial failed lookup](interior-source-junctions/initial-plane-membership-failure.log) is preserved.

Source-normal orientation classes enumerate 24 wall/sloped-plane edge candidates in A and 27 in B, plus 24 nonparallel wall/wall edge candidates in each. These are source candidates, not accepted image roof or room semantics. Four A roof/wall candidates touch previously compatible interior wall planes 8,12,25; two B candidates touch planes 10,14,26. This asymmetric result must not identify a component: finite subdivisions, T-junctions and near-coplanar plane classification can affect incidence counts.
