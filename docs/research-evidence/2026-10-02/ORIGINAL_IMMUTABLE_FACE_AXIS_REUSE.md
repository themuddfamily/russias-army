## Correction: immutable indexed data does not prove iterator order

The initial frozen-coordinate gate omitted custom array iterators. A concrete frozen zero-yield iterator caused the shared prefix cache to reuse a floor triangle normal for a wall and report a false initial overlap. The [iterator guard correction](ORIGINAL_CONVEX_ITERATOR_GUARD.md) preserves that failure and tightens new face-axis reuse to standard array iteration. Custom iterator inputs retain the original eager query behavior; the older pair cache is unchanged. The initial report and source hashes remain preserved, rather than treating frozen coordinates alone as sufficient proof.
