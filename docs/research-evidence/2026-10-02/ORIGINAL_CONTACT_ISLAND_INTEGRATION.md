# Coupled contact integration and live validation

The production world now uses stationary finite-feature queries from the current door-aware geometry at all four joint physics sites: Game callbacks, prediction replay, server controlled players and compatibility proxies. At zero-time angular contacts, it gathers touching fixed and dynamic constraints, solves detached body state, stages the known launcher `.85` linear-velocity mutation and silently projects every gathered constraint with zero restitution. Both solves must converge with finite output before state or callbacks become observable. Incomplete witnesses or invalid provider data retain the existing bounded response. Motion continues through the existing sampled rotating-hull sweeps after response; a current-pose solve never permits blindly advancing the remaining time.

The original force increments, `.05/10` stepping, source fuse, friction/restitution, 48-event cap, 128 solver iterations, tolerance, jump thresholds and network deadlines remain unchanged. Opening doors remain removed from physical contact queries. Notification once per active surface row is an explicit reconstruction policy; native notification multiplicity is unproved. Selected-row presence is required, but an impulse on another gathered row can permit commit. Gathering currently includes disconnected contact groups. Arbitrary external hooks can mutate velocities after the staged projection and lie outside its guarantee.
