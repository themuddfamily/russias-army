# Passive score and nested UI audio inventory

The [decoder](../../../scripts/research/audit-original-audio-timelines.py) examines the six preserved Director score frames in each edition and every root/nested sprite tag in all four exported SWFs. The two 48-byte score sound channels are entirely zero in each reconstructed frame. The D7 offsets are taken from the [pinned ScummVM parser](https://github.com/scummvm/scummvm/blob/4d360356e79eb6f0cd1fd0f77f6e686e6419f272/engines/director/frame.cpp#L1580); stream/frame parsing retains bounded delta provenance. This is a passive binary inventory, not execution of any original code.

Both UI SWFs contain one identical DefineSound13 at root frame 2: ADPCM format1, stored ratecode0, mono and 1,264,176 declared samples. Rootframe2 also contains StartSound13 with SOUNDINFO `04ffff`: a 65,535 loop count, with no stop/no-multiple/envelope/in/out-point flags. The 31 nested sprites plus root carry32 SoundStreamHead2 records but no SoundStreamBlock. Empty stream headers are not 32 additional audio tracks. The Barrack health and hurt-overlay SWFs contain no sound tags. Neither UI has an import tag in this inventory. [Machine results](../../../artifacts/fidelity-review/2026-10-02/current/audio-timeline-audit/source-audio-timelines.json) retain every source hash, timeline count, audio-tag hash and exact header/style values.

The tag fields follow Adobe's [SWF19 specification](https://open-flash.github.io/mirrors/swf-spec-19.pdf), sound chapter, printed pages177–183. The decoder freshly verifies its PDF hash `6a1625b0929a86329021d365ba079c7e1f51502dfb4ea7d92ec9947841625cdd` and pinned parser hash `334ca9e1f5821f751845ba34c494164bee9a36bcfc41d000a6d4ebd9100ba16a`. The stored sound is additional to the12 named Director cast sounds covered by the earlier [invocation audit](../2026-10-01/ORIGINAL_AUDIO_INVOCATION_AUDIT.md).

The primary [Director Scripting Reference](https://eclass.hmu.gr/modules/document/file.php/TP194/drmx2004_scripting_ref.pdf), printed page932, defines that property as thumbnail selection. It does not establish execution of this StartSound during texture creation. The decoded score's live Flash sprite at result/lobby frames references a different cast member; the source UI score-playback route is not established. The embedded sound therefore proves an available authored looping event, not the target game's audible playback lifecycle. It is packaged separately with its own decoding provenance; automatic browser soundtrack playback is not installed on the basis of this thumbnail operation.
